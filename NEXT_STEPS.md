# Чек-лист: своё VPN-приложение на этом модуле

Исправления в библиотеке уже в коде. Этот список — что делать дальше, по порядку. Пункты рассчитаны на сборку из терминала, без Android Studio.

## 1. Сборка на этой машине

- [ ] Поставить JDK 17. Android Gradle Plugin 8.5 на более старой Java не запускается.
- [ ] Поставить Android SDK: platform `android-34`, build-tools `34.0.0`, platform-tools (`adb`).
- [ ] В `V2ray-Android/local.properties` заменить `sdk.dir` на свой SDK. Сейчас там чужой Windows-путь `C:\Users\developer\AppData\Local\Android\Sdk`.
- [ ] Собрать debug:

```bash
cd V2ray-Android
./gradlew :app:assembleDebug
```

- [ ] Поставить APK на телефон или эмулятор: `adb install -r app/build/outputs/apk/debug/*-debug.apk`.
- [ ] Смотреть логи процесса UI и процесса `:RunSoLibV2RayDaemon`: `adb logcat`.

## 2. Проверить исправления на устройстве

Пример в `:app` — стенд, не готовый продукт. Пройти каждый сценарий на реальном телефоне.

- [ ] Вставить рабочий URI (`vless://`, `vmess://`, `trojan://`, `ss://`) или полный JSON со SOCKS inbound. Пустое поле и JSON без `protocol: socks` должны показать toast и не запускать сервис.
- [ ] Connect → в уведомлении и на кнопке сначала connecting, затем connected. Трафик реально идёт через туннель.
- [ ] Disconnect, сразу снова Connect. Туннель должен подняться заново, а не зависнуть в «подключено» без сети.
- [ ] Повернуть экран на экране примера. Activity не падает, кнопка и статистика остаются на месте.
- [ ] На Android 13+ отклонить уведомления. VPN-диалог всё равно появляется, соединение стартует. Уведомление при этом система может скрыть, пока разрешение не выдано.
- [ ] Отклонить системный диалог VPN. Сервис не остаётся висеть в connecting.
- [ ] Нажать замер обычного delay. Интерфейс не замирает на несколько секунд.
- [ ] Подключиться и нажать замер delay активного сервера. Если ответ не пришёл, через 5 секунд показывается `-1`, повторные нажатия не копят приёмники.
- [ ] Таймер идёт как обычные часы: после 58 секунд видно `00:00:59`, затем `00:01:00`.
- [ ] Переключить `VPN_MODE` / `PROXY_MODE` во время сессии. Старый сервис останавливается и поднимается выбранный режим.
- [ ] Убить процесс свайпом из недавних и снова открыть приложение. Кнопка не должна показывать вечное connecting, если туннель уже умер.

## 3. Своё приложение поверх `:v2ray`

Модуль `:app` можно заменить. Модуль `:v2ray` оставить целиком: Java, manifest, `libv2ray.aar`, `libtun2socks.so`.

- [ ] Новый application-модуль с `implementation project(':v2ray')`. Репозиторий `flatDir { dirs 'v2ray/libs' }` уже подключён в `settings.gradle`.
- [ ] В `Activity.onCreate` один раз на каждый экземпляр экрана вызвать `V2rayController.init(activity, R.drawable.ваша_иконка, "Имя приложения")`. Повторный `init` на том же экземпляре Activity ломает регистрацию системного диалога VPN.
- [ ] Старт: `V2rayController.startV2ray(activity, "название сервера", конфиг, null)`. Третий аргумент — пакеты, которые идут мимо туннеля, а не блок-лист.
- [ ] Стоп вызывать с главного потока: `V2rayController.stopV2ray(context)`.
- [ ] Слушать `V2RAY_SERVICE_STATICS_BROADCAST_INTENT` через `ContextCompat.registerReceiver(..., RECEIVER_NOT_EXPORTED)` и снимать приёмник в `onDestroy`.
- [ ] Хранить список серверов у себя (Room, DataStore или свой JSON). Пример держит одну строку в `SharedPreferences` под ключом `conf`.
- [ ] Не писать сырой конфиг в logcat: в URI есть uuid и пароли.

## 4. Конфиг и ядро

- [ ] Прогнать свои боевые ссылки через кнопку delay и через реальное подключение. Разбор коротких URI сидит внутри `libv2ray.aar`, у него бывают ошибки на редких параметрах. Для такого сервера надёжнее отдать полный JSON.
- [ ] В JSON для этого клиента обязан быть SOCKS inbound. Порт из него получает tun2socks. Шаблон библиотеки использует `127.0.0.1:10808`.
- [ ] `geoip.dat` и `geosite.dat` уже лежат в `libv2ray.aar` и копируются при `init`. Отдельный assets-каталог нужен только если вы подменяете эти файлы своими.
- [ ] Сменить иконку уведомления и имя приложения в `init`. Сейчас пример передаёт `R.drawable.ic_launcher` и `"V2ray Android"`.

## 5. Релиз

- [ ] Собрать `./gradlew :app:assembleRelease` и поставить именно release-APK. В `:app` включён R8. У AAR есть keep-правила для `go.**` и `libv2ray.**`, но сериализация `V2rayConfigModel` между процессами должна быть проверена на телефоне.
- [ ] Пройти connect / disconnect / повторный connect на release-сборке, не только на debug.
- [ ] Если приложение пойдёт в магазин, заранее решить судьбу `foregroundServiceType="specialUse"`: для VPN Google часто ждёт тип, который проходит их политику foreground-сервисов.

## 6. Осознанно не сделано

- [ ] IPv6. Сейчас в туннель попадает только `0.0.0.0/0`, IPv6 идёт мимо. Это отдельная доработка `VpnService.Builder` и tun2socks, её не стоит смешивать с текущими исправлениями.
- [ ] Свой парсер URI вместо `Libv2ray.getXrayOutboundFromURI`, если короткие ссылки вашего поставщика не поднимаются.
- [ ] Экран списка серверов, импорт подписки и выбор приложения для split-tunnel. В библиотеке для этого есть только `ArrayList<String>` пакетов в `startV2ray`.
